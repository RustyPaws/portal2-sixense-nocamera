# Portal 2 Sixense Perceptual Pack без специальной камеры

## Что это вообще такое

Есть игра **Portal 2 Sixense Perceptual Pack**. В ней кубы берут **рукой
в воздухе**: показываешь руку в камеру, сжимаешь кулак — и куб у тебя.

Беда в том, что игра хочет **особую камеру Creative Senz3D**. Её давно не
продают, и без неё игра вылетает или зависает с надписью «подключите камеру».

Эта штука чинит игру. Камера нужна **самая обычная**, любая веб-камера:
встроенная в ноутбук тоже подойдёт.

## Что нужно

1. Игра **Portal 2 Sixense Perceptual Pack** в Steam (бесплатная).
2. **Веб-камера**. Любая.
3. **Python 3** с [python.org](https://www.python.org/downloads/).
   При установке поставь галочку **«Add Python to PATH»**. Это важно.
4. **Visual Studio** нужна, **только** если ты скачал исходный код, а не
   готовый архив (см. ниже). Тогда ставь Visual Studio 2022 (бесплатная
   Community) с компонентом **«Разработка классических приложений на C++»**.

### Где взять

**Простой способ.** На странице проекта на GitHub справа есть раздел
**Releases**. Скачай оттуда архив `portal2-sixense-nocamera-….zip` и
распакуй куда угодно. В нём уже есть собранный файл, так что Visual Studio
не нужна, и **шаг 2 пропускай**.

**Сложный способ.** Скачать исходный код (зелёная кнопка «Code» →
«Download ZIP»). Тогда нужна Visual Studio и шаг 2.

## Установка

Делай строго по порядку. Каждый шаг делается один раз.

**Шаг 0.** Закрой игру, если она открыта.

**Шаг 1.** Открой папку этого проекта. Кликни по адресной строке в
Проводнике, напиши `cmd` и нажми Enter. Откроется чёрное окно, и оно уже
открыто в нужной папке.

**Шаг 2.** *(только если скачал исходный код, а не архив из Releases)*
Собери файл руки. Напиши в чёрном окне и нажми Enter:

```
hand\build.bat
```

В конце должно быть написано `BUILD OK`. Если написано что-то страшное
красным, значит, не стоит Visual Studio с C++ (см. «Что нужно», пункт 4).

**Шаг 3.** Почини игру:

```
python nocamera_patch.py
```

В конце должно быть `Done.`. Твои файлы игры не портятся: программа
сохраняет оригиналы, и всё можно вернуть (см. «Как всё удалить»).

**Шаг 4.** Подготовь программу, которая смотрит на руку через камеру:

```
tracker\setup.bat
```

Будет долго, она качает из интернета штуки для распознавания рук.
В конце должно быть `SETUP OK`.

Всё, установка закончена.

## Как играть

Каждый раз, когда хочешь поиграть:

1. Запусти **`tracker\run.bat`** (двойной клик). Откроется окно с
   картинкой с камеры.
2. Покажи руку в камеру. На картинке на руке должен появиться
   **зелёный скелетик**. Если появился — всё работает.
3. Запусти игру через **Steam**, как обычно.
4. Окно с камерой **не закрывай**, пока играешь. Закроешь — рука пропадёт.

### Что делать рукой

| Хочу | Делаю |
| --- | --- |
| Взять куб | смотрю на куб и **сжимаю кулак** |
| Нести куб | двигаю кулак, куб летит за ним |
| Отодвинуть куб дальше | двигаю кулак **к камере** |
| Повернуть куб | **наклоняю** сжатый кулак |
| Бросить куб | **разжимаю** руку |
| Увеличить или уменьшить куб | держу куб и нажимаю **V** |

Ходить, прыгать и стрелять порталами — как в обычном Portal 2:
клавиши WASD, пробел и мышка.

### Советы, чтобы работало хорошо

- Сиди примерно **в полуметре** от камеры.
- Свет должен падать **на руку**, а не из-за неё (не сиди спиной к окну).
- Куб берётся только **близко**. Подойди к нему почти вплотную.
- Когда сжимаешь кулак, держи руку **как тебе удобно**. В этот момент
  программа запоминает позу и дальше считает её «прямой».

## Окно настроек

Всё, что двигаешь в окне трекера, **сразу** работает в игре. Ничего
перезапускать не надо. Понравилось — нажми **«Сохранить»**.

Что крутить, если что-то бесит:

| Проблема | Где | Что сделать |
| --- | --- | --- |
| Рука трясётся | Сглаживание | «Сглаживание в покое» **больше** |
| Рука тормозит, отстаёт | Сглаживание | «Отзывчивость в движении» **больше** |
| Кулак не срабатывает | Захват | «Кулак, если раскрытость ниже» **больше** |
| Куб сам падает из рук | Захват | «Ладонь, если раскрытость выше» **больше** |
| Куб крутится сам по себе | Вращение | «Мёртвая зона» **больше** |
| Куб крутится слишком слабо | Вращение | «Усиление поворота» **больше** |
| Куб крутится в обратную сторону | Вращение | галочка «Инвертировать вращение» |
| Портал-ган смотрит в потолок или в пол | Прицел и движение | двигай «Высота пальца» |
| Рука ходит слишком мало или слишком много | Прицел и движение | «Масштаб движения» |
| Не та камера | Камера | «Номер камеры»: 0, 1, 2… |

Внизу под картинкой есть полоска «раскрытость руки». Сожми кулак: полоска
должна уйти **левее красной риски**. Раскрой ладонь: **правее зелёной**.
Если не уходит, двигай пороги на вкладке «Захват».

Испортил всё — нажми **«По умолчанию»**.

## Что-то не работает

**Игра пишет «Raise your primary hand» («Подними руку»).**
Игра не видит руку. Проверь, что окно трекера открыто и на руке есть
скелетик. Может быть, рука у края кадра: подвинь её к центру.

**В окне трекера написано «камера N не открывается».**
Камера занята другой программой (Zoom, Discord, браузер) или выбран не тот
номер. Закрой лишнее или поменяй «Номер камеры» на вкладке «Камера».

**Скелетика нет, хотя рука в кадре.**
Мало света или рука слишком далеко. Включи свет, поднеси руку ближе.

**Игра вылетает при загрузке уровня.**
Скорее всего, Steam обновил игру или ты нажал «Проверить целостность файлов».
Это откатывает починку. Закрой игру и снова сделай **шаг 3** установки.

**Управление в игре совсем сломалось.**
Нажми `~` (тильда, слева от единицы), чтобы открыть консоль. Если она не
открывается, включи её: Настройки → Клавиатура/мышь → «Включить консоль
разработчика». Напиши в консоли
`sixense_intel_enabled 0` и нажми Enter. Рука выключится, останется обычная
мышка. Включить обратно: `sixense_intel_enabled 1`.

## Как всё удалить

Закрой игру и напиши в чёрном окне (см. шаг 1):

```
python nocamera_patch.py --revert
```

Игра станет такой же, как была. Папку проекта можно просто удалить.
